Rest and Spread Operators

The spread operator expands an iterable into individual values. The rest operator collects multiple values into an array. Both use three dots: ....

1. Spread with Arrays

const first = [1, 2, 3];
const second = [4, 5, 6];

const numbers = [...first, ...second];
console.log(numbers); // [1, 2, 3, 4, 5, 6]

// Copy an array
const copy = [...first];

2. Spread with Objects

const user = { name: "Alex", age: 20 };
const updatedUser = { ...user, city: "Delhi" };

console.log(updatedUser);
// { name: "Alex", age: 20, city: "Delhi" }

// Later properties overwrite earlier properties
const changedUser = { ...user, age: 21 };

3. Spread in Function Calls

const marks = [85, 90, 78];

function add(a, b, c) {
	return a + b + c;
}

console.log(add(...marks)); // 253
console.log(Math.max(...marks)); // 90

4. Rest Parameters

Rest parameters collect all remaining function arguments into an array.

function sum(...numbers) {
	return numbers.reduce((total, number) => total + number, 0);
}

console.log(sum(1, 2, 3, 4)); // 10

function introduce(firstName, ...hobbies) {
	console.log(firstName, hobbies);
}

introduce("Alex", "reading", "music");
// Alex ["reading", "music"]

5. Rest in Destructuring

const colors = ["red", "green", "blue", "yellow"];
const [firstColor, ...otherColors] = colors;

console.log(firstColor);  // red
console.log(otherColors); // ["green", "blue", "yellow"]

const { name, ...details } = {
	name: "Alex",
	age: 20,
	city: "Delhi"
};

console.log(name);    // Alex
console.log(details); // { age: 20, city: "Delhi" }

Important Rules

  • Spread expands values; rest collects values.
  • Rest must be the last parameter or destructured item.
  • Spread creates shallow copies, not deep copies.
  • Rest parameters are always stored in an array.
